REPRODUCTION AND PROOF LIMIT
Initial preparation: node model-preflight.mjs --download
Local rerun with existing verified assets: node model-preflight.mjs
Each run validates the real 384-dimensional mean-pooled normalized embeddings,
three paraphrase rankings, and a second model reload in a fresh process with
remote model access disabled. The fresh process also blocks JavaScript fetch.
This proves local asset inference under those settings; it does not simulate an
operating-system network disconnect. No mocked AI fallback is implemented.
